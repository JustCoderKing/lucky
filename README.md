# lucky

双色球，大乐透出号工具

## 更新开奖数据

在项目根目录执行：

```bash
python scripts/fetch_draws.py
```

需要本机有 Python 3，并且能访问 `datachart.500.com`。脚本从 500.com 开奖表拉取双色球和大乐透，覆盖写入 `data/draws.json`。页面直接读这个文件。

不用改脚本。每次运行都会把截止日期设为当天，并向 500.com 请求从 `16001` 到期号上限为止的数据。期号上限是当年的 `999` 期（年份后两位加 `999`，例如 2026 年是 `26999`），因此当天已经开出的期次都会包含在内。写入文件时只保留 **2016-10-30** 至运行当天的开奖。

成功时终端会打印两个玩法的期数、跳过的行数、最新一期和最老日期，最后一行是 `wrote ...\data\draws.json`。任一玩法少于 1400 期时脚本会中止，不会改写已有文件。

本地查看：刷新浏览器。已经部署到 Vercel 时，把更新后的 `data/draws.json` 随站点重新部署一次。
